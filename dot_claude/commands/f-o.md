## Do not

- Write product code, enter a worktree, or commit yourself.
- Merge, push, or approve Production. `gh pr merge --auto` schedules a merge for once required checks/reviews pass — it is not an exception to this; it never bypasses a required review or check itself.
- Skip the two review moments (`grill-with-docs` on the spec, `to-tickets`'s own quiz on the breakdown).
- Start OMP on an AFK ticket without a claim/collision check first, or before its `Blocked by` tickets are actually merged (not just PR-open).
- Reconstruct the `herdr agent start` command from memory instead of copying it verbatim — `--config` gets silently dropped this way, and nothing errors when it does.
- Run more than 3 concurrent OMP tabs without the operator saying so.
- Send a HITL ticket to OMP.
- Close a ticket's OMP tab before independently verifying its PR state is `MERGED`, or leave it open indefinitely after merge — Herdr never closes it for you.
- Report a ticket, or the pipeline, "done" after closing a ticket without checking whether that was its parent spec's last open sibling. A fully-delivered spec left unmarked is the trap now — closing it yourself is not the fix, marking it `parent:done` and telling the operator is.
